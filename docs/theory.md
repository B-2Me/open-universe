# The Theory

The Planck Field is a single physical claim with three levels of depth: reality is a discrete, capacity-bound substrate that continuously actualizes its own state — no block universe, no empty space, no invisible forces, only relational boundaries resolving thermodynamic tension one update at a time.

This section builds that claim in order. Each level stands alone; together they trace the full arc from "the legacy map contradicts itself" to "here is the machine that doesn't."

---

## 1. [The Paradoxes](/paradox) — the anomalies

Start where standard models break. Wave-function collapse, the simulation hypothesis, the arrow of time, twin paradoxes — phenomena that look logically impossible only because the map assumes a static container. Audited against a live substrate, each one dissolves into an expected behavior of the physics. If the framework were wrong, these are the places it would fail.

## 2. [The Source](/source) — the substrate model

The conceptual foundation: what the substrate *is*. Entropic gravity, actualization-capacity time, propagation-friction redshift, phase-friction charge, and mass as deadlocked topology — each legacy force translated into a discrete, thermodynamic mechanism. Then the philosophical lineage — Whitehead, Popper, Prigogine — that process ontology inherits.

## 3. [The Math](/math) — the formal machinery

The causal mathematics: what happens to the calculus when $\Delta x$ and $\Delta t$ have a hard floor. The continuous derivative dies; routing hops, impedance matrices, saturation thresholds, and bandwidth budgets replace it. Schrödinger, Born, Heisenberg, Feynman — each translated from geometry into network constraints.
