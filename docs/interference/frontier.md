# The Open Frontier: Adjacency Expansion

*The following is the immediate roadmap for the framework — how the current 2D mechanics scale toward volumetric observables. None of this is implemented in the engine yet; it is the theoretical trajectory, kept honest by that distinction.*

The engine is already a flat 1D array — `calloc(PIXEL_COUNT, sizeof(PlanckNode))`. The "plane" exists only because the routing table wires node $i$ to specific neighbors via modulo arithmetic (`y·W + x`). There is no geometric container. It follows that "3D space" is not a stack of 2D sheets — it is simply a wider coordination number. Going from Oct8 (8 exits) or Hex6 (6 exits) to a 3D substrate means giving each node 12 (hexagonal close-packed), 14 (body-centered cubic), or 26 (3D Moore) valid neighbors in the same flat array. The field isn't deeper; it has more exit vectors per locus — more ways to dissipate thermodynamic friction.

*   **Gravity as congestion overflow:** on a wider graph, a saturated node's in-flight buffer can route overflow through the extra adjacency channels instead of stalling — 3D gravity is routing overflow across the expanded matrix, not an interlayer phenomenon.
*   **Cross-sections ($\sigma$) → waveguide shearing:** how many adjacency channels of a phase-locked knot must fail before the structure loses hydrodynamic integrity. *(The 2D engine already measures this natively — quantized severing counts in the bombardment scenarios.)*
*   **Resonance widths ($\Gamma$) → synchronization endurance:** the number of ticks a knot sustains phase alignment against ambient thermal jitter before unwinding into actualization yield.
*   **Quantum spin:** not an abstract intrinsic property but the routing-phase offset required to weave a self-sustaining standing wave through the expanded graph.

## Measured: The Adjacency-Expansion Experiments

*The following results were measured in `src/engine-sim.mjs` by widening each node's routing table with one extra adjacency channel (a counterpart at depth±1), carrying buffer overflow and deadlocked sends as pressure-driven, spinless flux. These are instrumented outcomes, not proposals — including a falsified hypothesis.*

*   **The Skin Effect:** at `hexjam` flux density, a single extra plane absorbs the entire 1.7M-quanta overflow — a 2D plane is an almost inexhaustible entropy sink. Mass penetrates exactly one slab deep. This is a measurement of why the universe defaults to flat quantum foam: rendering bulk 3D structure requires a thermodynamic event violent enough to saturate multiple planar capacities simultaneously.
*   **The Squeeze:** depth propagation beyond the first slab occurs only when the adjacent layer is itself congested (a seeded mid-jam forced mass through to a third slab, with a thin trickle reaching a fourth — each plane is another skin-depth barrier). When every reachable plane is jammed, the surface deadlock rebuilds to its un-expanded count: the relief valve works only while a non-jammed plane exists downstream.
*   **Quantized accretion pulses:** vertical mass transfer is not continuous — long static plateaus punctuated by discrete threshold-break events that dump a packet and re-lock. Accretion happens in packets, matching the framework's quantized exchange premise.
*   **The Dissipative Verdict (falsified):** we hunted a Z-axis standing wave — a volumetric resonant cavity — and it does not exist in this mechanism. Vertical overflow is *dissipative escape*, not elastic coupling: escaped flux diffuses across 160,000 nodes of planar capacity rather than building recoil. The cavity rings once, then equilibrates. **Collider-scale resonance cannot emerge from congestion alone; it requires an elastic restoring force** (e.g., a vertical structural phase-lock that binds node pairs across depth). This constraint is now recorded so the resonance hypothesis cannot be re-proposed without addressing it.
*   **Pipeline vs. Attenuator (falsified):** we measured tunneling by letting saturated ports leak a fixed ~1.6% of blocked flux (`+seep`, closed-ring `seepwall` scenario). Transmission is real — ~187k quanta crossed a supposedly hard wall — but **thickness-independent**: peak transmission was flat from t=1 to t=3. A mass-conserving buffer warehouses leaked flux and relays it at the same rate per hop; the wall is a pipeline, not a probability barrier. Exponential decay ($T \approx e^{-2\gamma a}$) would require per-stage *absorption* — each barrier node thermalizing a fraction instead of forwarding it. Bonus emergent finding: deadlock walls **thermally erode** even with zero seepage — refused arrivals still charge propagation heat, so no barrier in this universe is permanent.

## Re-audited under v3.0

*After the engine went fully discrete — integer momentum, argmax spin resolution, LUT quadrature budget — and unwinding began conserving mass as radiation spray, we re-ran the falsified experiments to check the verdicts hadn't been artifacts of the old approximations. One refinement: mass penetrates measurably deeper (a persistent ~3.7k reaches the third slab where the transient used to flash and die) — unwound radiation keeps feeding the squeeze — but it remains escape, not oscillation. The elastic-restoring-force constraint stands.
*   **Tunneling — confirmed, mechanism sharpened.** A weak retention gradient exists early (+~12%/layer at t=100) but washes out by t=200. Buffer decoherence now taxes in-transit staged flux, and spray deposits dissolved wall mass *outside* the barrier — the exterior count conflates transmission with erosion. Asymptotic attenuation still does not emerge.
*   **New phenomenon — thermal self-regulation.** Under v3.0, structures park hot cells just under the thermal limit and vent via unwinding spray — a thermostat made of microscopic detonations. The float-era `hexcycle` fixed point was an artifact of permanent deadlocks absorbing the mismatch as heat sinks; the discrete dynamics run hotter and regulate themselves. What reads as "leaking" in the entropy layer is this radiation simmer — honest physics, not a bug.

## Causal Mechanics Probes (Stage 1–2)

*Two instruments were added to `engine-sim.mjs` to test causal-mechanics claims against the shipped engine — neither required new physics in `planck.c` to produce a measurement.*

*   **Distance is propagation latency — confirmed, with structure** (`+latprobe`, overdensity pulse vs. pulse-free control): on a free corridor (`hexstream`) a density wave transits 281 cells in 134 ticks ≈ **0.48 ticks/cell** — the wave outruns bulk transport (a sound-like mode). Through `hexjam`'s upstream pressure pile the wave crosses 152 cells in 63 ticks ≈ **0.41 ticks/cell** — a congested field is stiffer, not slower, for the signal. But below the throat the tagged mass **never arrived** in 340 ticks — even at 120-cell gap width. Signal latency is congestion-insensitive; *bulk* latency is set by port throughput and can become effectively unbounded. Distance-as-latency is real; the wall is a selective membrane, not a speed bump.
*   **Halving wave on head-on conflict — real but outgunned** (`+halve`, conflict-scoped ½-opposing + ¼+¼-lateral momentum split on `cs === d` arrivals): inert on `hexcycle` (300/300 through t2000 — the scope correctly never fires on healthy circulation), `hexcycleb`, and `hexjam`. On the new `hexcollide` variant (two 180° streams meeting head-on) the mechanism is measurable — early spray −12%, surviving knots +38%, mass spread into more sectors (balance 0.15 vs 0.11) — but the front still detonates at 65535 by t50. The acoustic channel exists and redistributes laterally as predicted; at this energy density it cannot prevent the blowoff. Flag-gated pending a decision on split fractions or lower-energy scoping.
*   **Stateless pressure asymmetry — falsified as gravity** (`+press`, per-tick neighbor occupancy → momentum bias): nearest-neighbor pressure is a *contact force*, not a field — it cannot act beyond one cell, so `hexlens` at impact parameter 50 feels nothing, and on `hexcycle` it pulls the ring's own halo inward until circulation collapses (300/300 → ~40/300 by t200). Occupancy-summation "gravity" produces local collapse, not curvature — a useful negative result: gravity needs a propagating carrier.
*   **Propagating tension field — stable and benign, but streams accrete rather than lens** (`+tension`, `hexlens` variant): deadlock-gated occupancy emits a u8 scalar that diffuses at channel-share rate and decoheres per-tick — a real graded well with finite range (ℓ ≈ √(D/λ) ≈ 10–25 cells at tuned values). The field passes its hard regression: `hexcycle` survives 300/300 to t1000 (the q=90 ring sits below `T_EMIT_MIN=200`, so bound circulation neither emits nor is disturbed). But on `hexlens` every steering coupling shows the same binary cliff — spin-pull (argmax) either can't reach the 60°-quantized turn threshold or spirals the stream into the knot; duty-cycling only slows capture; flux-shear (arrival deflection into the up-gradient buffer) is invisible at ≤1/32 and accretes at ≥1/16. Streams are sticky mass flows, not rays: a well strong enough to bend one is strong enough to eat it. Two honest paths remain — measure the capture cross-section vs. impact parameter as the substrate's actual "gravity," or replace diffusion with ballistic tension transport for true long-range reach (B=50 is outside diffusive range on experiment timescales).
*   **Accretion cross-section measured — the substrate's native gravity** (`hexlens`, `LENS_B` sweep at `T_DIVERT=4`, shear-only coupling): the capture curve is structured, not monotonic. Direct hits are *erosive* — a stream at B=15 strips the knot below its own baseline (capD 98→50, a tidal-stripping analog); the balance point sits near B=20; **grazing incidence captures** — at B=25–30 the sheared boundary-layer mass binds into new deadlocked cells around the well (+65 to +95 knots, an accretion-disk analog) while the stream sheds ~55% of its quanta; and the interaction cuts off at B≈35, exactly the diffusive reach ℓ. The threshold is sharp in coupling strength: `>>4` shear accretes, `>>5` is transparent at every B. Gravity in this substrate is not trajectory curvature — it is local accretion, stripping, and capture via a propagating tension gradient, strongest at the well's edge rather than its depths.
*   **Suite sweep + oct8 parity — shear-only coupling settled**: running `+tension` across the full scenario suite shows one consistent signature — the field is *anti-compressive*. `hexcycle` is inert (ring below `T_EMIT_MIN`); `hexsnow` accretion is suppressed ~4.5× (351→76 knots — sheared infall misses the sink); `hexjam`'s own wall emits a field that disperses the upstream pile (4140→2053 deadlocked); `hexbraid` junction knots drop ~45%. The oct8 port produces the identical signature (`electron`: 1390→89 knots) with a graded radial profile — the mechanism is substrate-independent. Spin-pull coupling was rejected: duty-cycled torque on top of shear collapsed `hexsnow` further (21 knots) while adding no structure. Shear-only keeps the port to three parameters and no timing machinery. Because the field legitimately rewrites barrier/accretion scenarios, any `planck.c` integration belongs behind an off-by-default flag.
*   **Congestion gravity is load-bearing — the two mechanisms compose, not compete** (`+nograv` under the tension baseline): removing the `cong` steering from `hexjam` is catastrophic — the stream detonates on the wall face (spray peaks at 4M quanta, the wall unwinds and stops emitting). Congestion gravity is the *near-field* routing layer (steer flux off saturated ports); the tension field is the *far-field* propagating layer (gather, strip, bind at range). Same congestion physics, two scales — both stay.

## The Kinematics Campaign (Stage 3): Can Matter Move?

*The following was measured on `planck3.wasm` via the headless harness suite (`script/sweep.mjs` → `boost.mjs` → `collide.mjs` → `quench.mjs`) over the True-FCC lattice. The program set out to map a topological S-Matrix; what it found instead is a measured property of the substrate — bound structures do not translate.*

*   **The particle dictionary — 37/37 stable specimens.** `pathfinder.mjs` exact-traces closed port cycles under the Phase-Lock ≤60° constraint; `sweep.mjs` ticks each seed 400 ticks in `planck3.wasm` and records invariant mass, RMS cross-section, spray/deadlock telemetry, and per-window series. Every measured specimen holds its traced spins bit-perfectly — the substrate sustains matter exactly as RFC-048's law predicts: *closed streamlines by construction are sufficient*.

*   **Boundary-flux boost — survives everything, moves nothing.** `boost.mjs` drives quanta/tension/spin/heat envelopes through 24 axis+polarity boundary vectors into a resident knot. At every survival-safe flux the skeleton centroid does not displace — not a fraction of a cell. The knot neither rides the beam nor is pushed by its tension gradient; at destructive fluxes it erodes in place. First datum for lattice-locking.

*   **The pinch "S-Matrix" — no ballistic channel exists.** `collide.mjs` dual-spawns two dictionary knots ±`separation` on an FCC axis and applies a symmetric ADSR tension pinch (peak 20) at both walls. For ~825 ticks of a 1000-tick run the gap is frozen to two decimals — the pinch *never propels the knots together*. The t=999 outcomes are not scattering events: head-on identical twins undergo an asymmetric erosion race at ~92 cells of residual separation (retain 0.01% vs 4.2% — resolved by `symmetric_swapped`: reversing the axis flips which mask retains, so the ~4% floor is a **positional update-order artifact** of the row-major serial scan, not a property of either knot), while glancing `b=15` "fusion" is **halo bridging** — accreted ambient mass containing B's painted markers, not physical knot contact (gap never closes below ~128). Reinterpreting the b-sweep: it maps halo-bridging reach vs lateral offset, not a scattering cross-section.

*   **Galilean spin boost — falsified as momentum.** A uniform drift vector blended into each cell's circulation spin (requantized to the nearest FCC port) should advect the knot if spin is a momentum carrier. It does not: the boost is a wound, not a velocity. At mag≥0.5 the requantization breaks the phase-locked circulation — live mass collapses ~80% within 25 ticks, the remnant live-centroid wanders ±15 cells, and no component ever propagates ballistically. With painted provenance static at spawn, translation was tracked by a new live-component centroid channel — which never moves. Second datum: injecting "momentum" as spin direction shreds the structure instead of propelling it.

*   **Lattice-locking — the synthesis.** Three independent momentum mechanisms — external tension pinch, directional wall flux, and internal spin-field drift — all fail to translate a bound structure. Matter on this substrate does not advect; it erodes, sprays, and reconstitutes elsewhere (the ±13-cell remnant wander is migration-by-reformation, not motion). The implication for the ontology: inertia is routing friction — a defect's phase-locked circulation is load-bearing topology, and "moving" it means destroying and rebuilding it. There is no ballistic channel, so particle interactions are proximity/contact-mediated, not collision-mediated — the S-Matrix program as classically posed is answered: the elastic threshold is absent because the projectile is absent. If anything here deserves the name "motion," it is propagation-by-reconstitution — which makes chiral nucleation (can the lattice *grow* a closed knot from an open arc?) the operative dynamics question rather than scattering.

*   **Capacity-stealing probed directly — the quadrature budget shows its choke.** `quench.mjs` (Audits §3) paints a controlled heat deposit on a beam-loaded channel vs an off-beam control. Two instrumentation facts reshaped the probe: cooling is quadratic (`(1+ts²)·diss·BWF[routing]`, ts=h/200 — a 20k deposit evaporates in one tick), and sustained beams *deplete* in transit (~15-cell half-life), so load is maintained by a source-zone channel. The honest observable is equilibrium heat, not deposit decay (the quadratic drain drowns a 300-unit deposit when baseline ≫ deposit): loaded channels hold **h≈1,400–1,600 steady-state vs ≈2 ambient** — routing load measurably prevents cells from shedding heat. *(Sync-corrected figure: under the mass-conserving `g_sync` update — deferred pushes persist rather than evaporating at publish — the same loaded equilibrium settles at **h≈410–450**; the ~3.4× drop is the phantom-mass leak priced in, not a change in mechanism. The load-vs-ambient contrast — ~200× — survives either engine.)* The negative control is the sharpest signature: buffer-loaded cells (energy-dense but unrouted by design) emerged into a self-choked state — parked quanta emit tension → congestion → routing saturates → `BWF→~0` → cooling off — stabilizing at h≈37,000 where generation finally meets the residual drain. Capacity-stealing exists in the engine not as an imposed rule but as an emergent fixed point.

*   **Engineering audit — the stale-state-pointer bug.** `planck3_state_pointer()` returned `g_rd`, which ping-ponged between two buffers each tick; every harness that cached it injected into the retired buffer on alternate ticks (~half-strength drives) and read a one-tick-stale frame half the time. Bit `boost.mjs`, `collide.mjs` (pinch ran ~half envelope strength across the collision matrix — the frozen-gap conclusions stand, since centroids were static on *both* buffer parities), and `quench.mjs`; the browser path was immune (it never sees the raw pointer). Fixed engine-side: flat tick now publishes via `memcpy`-back into a fixed `g_rd` — the pointer is permanently stable, dynamics verified bit-identical (0 mass-channel diffs flat/chunk/ordered + JS reference, `totQ=1,678,260` across all modes), ~1–2% memcpy overhead. Recorded so no future harness re-learns it.

## The Nucleation Campaign: Can Matter Grow?

*With motion falsified, the remaining dynamics question is growth: can the lattice close an open chiral arc, and can raw flux condense into a loop at all? Two instruments — `script/anneal.mjs` (scaffold repair) and `script/fountain.mjs` (sustained chiral injection), same census: live cells, free ends (live spin → dead target), longest live spin-cycle, nontrivial-cycle count.*

*   **Arc repair — topology healing is real, threshold ~0.55–0.6, geometry-dependent.** Cutting a contiguous arc from `hopfion_25_9`'s longest cycle (2001 cells) and releasing it: **≥0.60 re-closes** — the free tail erodes ~1 cell/tick until the surviving fragment spontaneously phase-locks into a ~1,000–1,140-cell closed cycle (`freeEnds→0`, durable through t300). **0.55 is the phase boundary** — a 100-cell cycle transiently forms at t≈97 then *ruptures* (remnant mass exceeds the small orbit's carrying capacity — a hydrodynamic blowout), and the fragment shatters into dozens of open strands. **≤0.50 dissolves.** The control (`hopfion_30_9`'s longest loop) fails at 0.6 *and* 0.8 — fragmentation cascade, 721 free ends — so repair is **parent-geometry-dependent**: the ~1,000-cell convergence is not a universal lattice attractor, and the closure threshold is a property of the specific winding, not a constant.

*   **Sustained feed does not substitute for scaffold.** Pinning a sub-threshold arc's tail to 80q/tick (`fountain.mjs --mode=tail`, arc=0.5) reproduces the blowout signature exactly — transient 185-cell cycle at t≈350, rupture, then freeEnds→353. Raw flux poured into an open end cannot buy what missing topology would have provided.

*   **The chiral fountain — strong nucleation falsified under every confinement regime tested.** A ring of 24 aperture cells at mid-plane, each forced to a tangential+0.6·up spin and 80q/tick (`--mode=ring` — nothing chiral is ever painted except the aperture spins): in vacuum the stream sprays laterally (~830 live steady-state, ~95% free ends, `maxCycle=2` forever — zero self-organization, the predicted impedance-free limit). An ambient `--foam=5` noise floor decays in ~25 ticks and never confines (38.5k/39k free ends). Convergent wall quanta (`--pinch=5..20`) cannot form a steady vessel — injected mass has no drain, so every strength floods toward saturation into the same micro-cycle soup (maxCycle≤5, nCycles~40 — dimers and trimers, never a soliton). The corrected vessel — a `tension`-register wall shell (`--ptension=60`, pressure gradient with zero mass injection) — confines nothing: ~1,839 live, ~95% free ends, `maxCycle=2`. **Verdict: raw chiral flux does not self-curl into phase-locked cycles under vacuum, noise bath, mass confinement, or pressure confinement.** The lattice sustains exact topology and repairs near-complete topology; it does not invent topology — nucleation in the strong sense is bounded below by a ~60%-complete compatible scaffold in every regime instrumented so far.

*   **Artifact sweep — the retention "constant" was update-order grain.** `symmetric_swapped` (bsweep finale): `retainA=0.0423, retainB=0.0001` — the mirror image of the unswapped head-on. Survival follows **position along the spawn axis**, not knot identity: the row-major serial update deterministically disadvantages one end. Every collision asymmetry measured to date traces to scan order, not to the knots — the S-Matrix campaign stayed benched pending a synchronous-update mode.

*   **Synchronous update built — and the residual asymmetry is deeper than scan order.** `planck3.c` now supports `g_sync` (`planck3_set_sync`): the two mid-tick push sites (tension-shear divert, thermal-unwind spray) defer into a queue that flushes into `g_wr` before publish — uniform `g_rd` reads all tick, and diverted mass persists (legacy semantics silently vented it at the publish `memcpy`; `symmetric_swapped --sync` shows ~101k live cells at t999 vs ~37k legacy). Legacy mode remains the bit-identical default (0 mass-channel diffs, all modes + JS reference). Under sync, `symmetric_swapped` returns `retainA=0.2594 / retainB=0.0039` — the positional bias *survives* synchronous update, and the likely source is the substrate itself: the ABC-FCC port set is **chiral** — x-mirror maps zenith planar dirs {1,3,5} onto nadir-only dirs {2,4,6}, so no +z port exists with a −x planar component. Mirrored x-positions are inequivalent environments; the only true mirror plane is ⊥y. Discriminating run in flight: y-mirror pair `ymirror_axis1`/`ymirror_axis5` under sync — the port set IS y-symmetric, so mirrored outcomes are required if the residual is geometry rather than code.
