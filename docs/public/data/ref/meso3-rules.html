Data Layout, Tick Execution Pipeline & the Three-Kernel Engine Family

1. Coordinate Stencil & Even-Parity Sub-Lattice

The substrate runs on a 3D Face-Centered Cubic (FCC) lattice mapped onto a regular cubic coordinate array. Only the even-parity sites exist as physical nodes:

Physical Site Condition: (x + y + z) % 2 == 0

Odd-parity coordinates (where (x + y + z) % 2 != 0) are non-sites and hold zero memory. Because of this parity geometry:

  • Face-diagonal neighbors: 12 channels with step size (±1, ±1, 0), (±1, 0, ±1), (0, ±1, ±1). Because (±1) + (±1) + 0 = 0 or ±2 (even), single-step hops always land on valid even-parity sites.
  • Axial neighbors: 6 channels with step size (±2, 0, 0), (0, ±2, 0), (0, 0, ±2). Axial steps use stride 2 so that hops never land on invalid odd coordinates.
  • Stacking: Classic 12-neighbor close-packed crystal structure with A-B-C-A-B-C plane stacking.

typedef struct __attribute__((aligned(64))) {

Registers present in meso3i but stripped in production (dwell delay lines, Q-cores, gates, fields, phase offsets) are the exploratory scaffolding — meso3i stays the canonical audit reference; core/perf carry the verified thermodynamic triad only.

3. The Ordered Tick Execution Pipeline (7 Steps)

Every tick advances the universal state machine through seven deterministic phases inside void meso3i_tick(void):

Step 1: Edge Delivery (Sub-Light Delay Line)

If DWELL > 1, quanta waiting in stage 0 of the edge buffer arrive at their destination nodes and land in local channel buffers. All deeper delay stages shift down by one slot (j → j - 1). (Canonical: DWELL=1 — direct hop.)

Step 2: Synchronous Density Snapshot

Every node computes its total local mass: mass = moving_channels + scalar_rest + directional_rest. This is cached globally into iR[site] so subsequent routing and friction decisions see a completely synchronous snapshot of the lattice.

Step 3: Local Node Interactions (collide_node)

Executes locally at every site without cross-grid communication:

  • Transit Cadence: If moving mass is present, iLT++; if quiet, reset iLT = 0.
  • Carrier-Gated Boil-Off: Parked mass can re-emit into moving channels. When IFRICM < 0, emission requires a transiting carrier dwelling for at least ILAT ticks. If IDREST=1, quanta return to their original directional channel.
  • Thermal Spontaneous Decay: If excitation iE > 0, the node probabilistically sheds bound energy (iE--) and emits a free photon (Einstein A21 spontaneous emission).
  • Pair Capture (Breit-Wheeler / Winding): Opposing quanta meeting head-on {c, -c} probabilistically bind into rest mass, locking the collision axis in directional rest.
  • Pair-Group Collision Shuffle: Two moving quanta are picked. The engine computes their vector sum c_i + c_j, looks up the equal-sum momentum group from GPAIRS, and swaps them for another member pair. Mass and momentum are conserved exactly.

Step 4: Core Clock Emission & Overflow

If Q-mode is active, nodes on their local clock beat emit excess core mass into moving channels. Any core mass exceeding capacity migrates to the lowest-density neighbor (gradient conduction). (Canonical: IQMODE=0 — skipped.)

Step 5: Mass Streaming (Spatial Transport)

Quanta in moving channels attempt to advance along their channel vector c:

  • Rest Mass: Remains stationary at the current node (Δx = 0).
  • Transit Drag (Space-as-Friction): If the destination density iR[dest] >= IFRIC, arriving quanta shed momentum and park into directional rest (or thermalize into excitation iE under IPHOT ≥ 6).
  • Elastic Reflection (Wall Refusal): If destination density exceeds IREFL, the hop is refused deterministically — the quantum reflects onto the opposite channel (c ⊕ 1) at the source node. No RNG is consumed — a hard congestion wall, not a probabilistic one.
  • Free Flight: Otherwise, quanta land cleanly in channel c at the destination node.

Step 6: Massless Photon Streaming & Matter Coupling

Photons advance along directional channels (iPA → iPB):

  • Vacuum Flight: Photons never collide with each other; speed of light c = 1 hop/tick is invariant.
  • Absorption (IPHOT ≥ 5): Per-quantum roll against post-stream parked mass — absorbed photons raise bound excitation iE += ν (energy-conserving).
  • Ablation (IPHOT 3–4 / stimulated IPHOT=2): Photons eject parked mass onto the photon's own channel — radiation pressure, momentum conserved.
  • Pair Production: Converging or opposing photon beams in vacuum fuse into rest mass (IPHOT ≥ 8, energy and momentum conserved).

Step 7: Double-Buffer Swap

Pointers swap (iA ↔ iB, iPA ↔ iPB, iRA ↔ iRB), and the global clock advances (ITICK++). core/perf land the final state back in the read plane — no pointer swap needed.

How meso_perf keeps bitwise parity while skipping cells

The insight that makes the optimization free of correctness cost: empty cells consume zero RNG draws in every phase — collide, stream, and pair production only draw on sites with content. Skipping them changes speed, never the random stream. The invariants that make it exact:

  • si-ascending processing — all phases iterate sites in row-major iidx order (meso3i's z,y,x), or the RNG draws map to wrong sites.
  • Global stationary carry — rest/drest/n/lt are copied for all actives before streaming; per-site copies inside the loop would wipe arrivals written by earlier sources.
  • Fresh-only zeroing — a first-touch destination is cleared with a 64-byte memset only if it wasn't already carried (iACT == 0), replacing the O(IN) full-plane memset.
  • iPTF flat cadence register — persistent per-site counter (mirrors meso3i's iPT plane), updated only for touched sites; quiet sites stay 0 forever.
  • Generation-stamped next-list — iNNF[si] == NGEN dedupes arrivals without clearing a flag array each tick.

5. The Parity Invariant (what bitwise-identity actually requires)

Bitwise-identical trajectories across kernels require the exact same RNG consumption order, not just the same rules:

  • Site order — collide and stream phases must visit sites in the same sequence (flat ascending si).
  • Short-circuit draws — friction rolls consume RNG only when iR[ni] ≥ IFRIC; absorb rolls only when parked mass is present; pair-capture rolls only when both channels are occupied. Gates must short-circuit identically.
  • Loop-bound dynamics — the emission loop bound u < n[REST] + dsum shrinks as mass depletes mid-loop.
  • Channel-batch vs per-quantum — friction parks an entire channel batch on one roll; absorb rolls once per photon. The granularity is part of the physics.
  • Deterministic paths — IREFL is a hard wall (no draw); seeded init leaves irng = 0xC0FFEE untouched (the 4th init arg is the axial flag, not a seed).

Practical consequence: cross-engine parity holds under the canonical ν=1 photon configurations (phot ∈ {5,6}, IDREST semantics, flat friction). ν > 1 frequency physics is meso3i-only (NNU=4 bins).
