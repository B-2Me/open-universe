## What qi3 adds (the absorber side — where QM lives)

link3's gap was absorber response: lumps had ONE excitation register (iE —
a scalar bank). Real absorption is selective: a transition either completes
at a matching energy or doesn't happen. qi3's sites carry an internal
LEVEL STRUCTURE:

### The edge-first rule (fundamental design decision)

Structures form BETWEEN nodes — in channel state — the way link3's
exchange bond lived in the gap traffic, not in either lump's
internals. A node's internal registers may be complex (they have to
drive complex edge states), but the goal is to DERIVE the resulting
state — never enumerate it. No hardcoded level table (`n=1,2,3`);
the internal dynamics produce configurations, and the observable
level is read off the structure by measurement.

**The heartbeat model:** edges react first. An offer arrives on a
link; a confirmation arms on the reverse link; when the confirmation
pulse returns, the node's edge PATTERN flips — the "level" changes
because the circulation changed, not because a counter incremented.

### Registers (spelled-out naming — long names document the ontology;
### inner-loop helpers may stay shorthand)

- `qWinding[site][c]` — the site's internal circulation: winding/
  momentum population per channel. Complex machinery that drives
  the edge states — the level is DERIVED from the pattern, never
  an enumerated value stored here
- `qCharge[site]` — bound charge (deposits from completed transactions)
- `qConfirm[site][c]` — pending confirmations per channel: offers
  received, responses armed (the TI's confirmation wave made a register)
- `qLevel[site]` — DERIVED, not stored: read off the edge
  configuration by measurement. The spectrum is generated by the
  dynamics, not hardcoded — we observe which stable patterns
  emerge, we don't enumerate them in advance

### The transaction (replaces absorb-on-contact)

Absorbers are per-EDGE, not per-site, and statistical in extent: we
don't know how large an absorber is at Planck granularity — it may
span one edge or twenty. Everything is in a way an absorber; "where
the absorber is" is a derived/statistical question per tick. One tick
evaluates ALL edges on ALL nodes simultaneously — each channel's
offers judged independently against that edge's own state, decisions
buffered (no order dependence within the tick).

1. Photon (offer, ν) transits a site on edge c
2. The EDGE evaluates: does ν match a transition this edge can
   express? (derived from that channel's winding/mass density — an
   extended absorber is a contiguous region of absorber-active edges)
   - match → arm a CONFIRMATION on the reverse channel
   - no match → photon passes (the offer declined — no partial fills)
3. Confirmation returns / completes the transaction: photon absorbed,
   the edge's state transitions (level change = circulation change)
4. Emission: an excited edge can fall to a lower stable configuration,
   emitting ν = the transition (spectrum = structure)
