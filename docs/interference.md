Because the lower layer actualizes millions of times faster, it completely dissipates its history between each macro-shift. This temporal gap prevents feedback vortices. The universe cannot maintain a perfect chain of dominos because the lower-level substrate is constantly overwriting its own relational geometry.
*   **The Biological Swerve:** Because the deterministic chain is physically broken by this memory wipe, living organisms have the latency required to utilize recursive feedback loops. By simulating our own futures and feeding those predictions back into our neural architecture as new inputs, we intentionally alter our own trajectories. We are not falling dominos; we are active, metabolic engines constantly swerving against the drift.

Worst case: `TENSION_SHARE` — hex6 exported `6·(tn>>3)` ≈ 75% of the field per tick while oct8 exported `8·(tn>>3)` ≈ **100%** (a full swap, different diffusion physics), and a hypothetical 12-neighbor lattice would overshare the register *negative*. Heat diffusion had the same shape (hex 2/3, oct 8/9 export). Fixed in both engines with normalized per-channel shares — `3v/(4·deg)` tension, `2v/(3·deg)` heat — which reduce **bit-identically** to the legacy shifts at deg=6 (hexcycle trace unchanged) while pulling oct8 back to the same 75%/67% export fractions (`octmix` re-verified: 197 knots, breathing; `electron` relaxes slower under cooler diffusion — 350→112 — without runaway). Remaining known misalignments logged for the eventual 3D substrate: the `DEADLOCK=200 < BUF=255` threshold stack means buffer-overflow relief always arrives *after* occupancy already froze (RFC-045's register mismatch), `NODE_BANDWIDTH_MAX=220` assumes ~6-channel routing load, and the z-channels deliver arrivals *spinless* — a phase-dropping sink can vent mass but can never host a Hopfion's topological winding.
*   **Latent bug exposed and fixed — `BWF_LUT` u8 wraparound**: the vacuum floor was the first configuration that made a real defect visible. `BWF_LUT[r] = round(256·√(1−(r/220)²))` evaluates to **256** for r ≤ 13 — which wraps to 0 in the `uint8_t`/`Uint8Array` table, silently zeroing heat dissipation for any cell with routing load ≤ 13. Invisible under dead vacuum (nothing generated heat to dissipate); under the q=1 floor every cell generated ~24 heat/tick against zero drain — a linear heat ratchet that pinpointed the defect. Fixed to `uint16_t`/`Uint16Array` in both `planck.c` and the harness — this is a canonical physics change: low-routing cells now dissipate as designed (`hexcycle`/`hexjam`/`octmix` re-verified clean under the fix).
*   **Chunk+halo memory architecture for the 3D engine — RFC-049 PASSES with a measured tradeoff** (`src/planck3.c`, verified native -O2 AND in wasm — `planck3.wasm` halo mode reproduced the JS t400 state with 0 mass-channel diffs via state dumps `test/fcc/t0.bin`/`t400.bin`): the FCC substrate was ported to C with three selectable memory models — flat `Node3[N3]` with arithmetic neighbors (control), the RFC's 20³-interior/22³-block chunk+ghost-ring architecture (halo exchange each tick, pushes resolve the owner chunk arithmetically — no cross-chunk pointers stored), and an ordered-chunk variant (chunked storage, flat global sweep order, no ghosts). Results at 100×100×40 on the RFC-048 Hopfion state: **C flat vs JS harness — 0 mass-channel diffs over 400 ticks** (q/s/b/tn byte-identical on all 400k cells; heat differs only by floor-RNG streams, which never feed back into mass). **Criterion 2: bit-identical port achieved.** Criterion 3: halo chunks run **1.15–1.7× faster than flat** (24–28s vs 29–47s per 400 ticks native -O2 — locality plus cheaper add-only neighbor indexing vs flat's 24 modulos/cell). The honest wrinkle: under knot conditions (injected 8³ saturated blob, where tension-divert/spray pushes actually fire), halo mode diverges — 125k cells differ at t400 — because pushes are ordered by global (z,y,x) position in flat but by chunk-order in the halo sweep; the speed *is* the reordering. The ordered-chunk mode stays bit-exact everywhere (0 diffs under knots) but costs 0.6× flat — per-neighbor owner resolution eats the block-scan win. Verdict: all three engines share one `fcc_node_tick`; halo is the production path for the laminar regime the engine exists for (stable structures emit zero pushes — measured spray=0/divert=0 across the acceptance run), flat/ordered remain the exact references for congested transients. Chunked storage also deletes the 20MB `NT3` neighbor table. The wasm build (`planck3.js`, `createPlanck3`) is wired in `src/build.sh`; DFS paint remains harness-side — the C engine consumes traced states via `fcc_set_node`/bulk load.
*   **WebGL2 volume renderer — RFC-050** (`docs/.vitepress/fcc/main.js` + `FccViewer.vue` + `/fcc-viewer`): the engine's {quanta,spin} registers are packed in-place into an RG8 buffer on the Wasm heap (`fcc_rg_refresh`) and uploaded per frame via `gl.texSubImage3D` — zero JS array copies, per the directive. Vertex shader does `texelFetch` per `gl_InstanceID`, culls vacuum and the tomographic Z-slice off-screen, and applies the honest embedding — the substrate is stacked-hex with parity-free ports (the ABC stagger lives in the port offsets, not layer origins), so nodes sit at `x + 0.5·(y&1)`, `y·√3/2`, `z·√(2/3)≈0.816`; a literal `z%3` layer shift would misstate the connectivity. Spin classes color the knot — equatorial (toroidal) warm, zenith cyan, nadir violet. Deviation from §1: bulk state loads via `fcc_load_pointer`/`fcc_load_commit` (P3ST blob → wasm memory in one `HEAPU8.set` + C-side unpack) rather than 400k `set_node` calls. Physics budget is adaptive — a tick costs ~80ms in wasm, so the viewer self-throttles rather than stall the UI; HUD reports real ms/tick.
*   **True FCC (ABC) substrate + a stable multi-loop 3D Hopfion — RFC-048 PASSES** (`hopfionx` on the parity-free lattice; `printSlice` tomographic viewer): the A-B-A-B parity interleave is replaced by a parity-free 12-port geometry — every layer offers zenith ports {1,3,5} and nadir ports {2,4,6}, so a single port index hops the identical offset layer-to-layer and traces a straight 3D diagonal through the A→B→C→A cycle (the RFC's z%3 azimuth cycling is the same invariant stated layer-relatively; the fixed-triple form makes reciprocity immediate — **4,740,000 edges, 0 broken**). The descent port that HCP deleted on alternating layers now exists everywhere.
